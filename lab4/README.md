# Двонаправлений хвильовий пошук у лабіринті

Навчальний проєкт для візуалізації роботи двонаправленого хвильового пошуку у лабіринті. Алгоритм одночасно розширює фронт від старту і від мети, що дозволяє значно швидше знаходити шлях у великій сітці, ніж класичний однонаправлений пошук у ширину.

## Що показує застосунок
- Візуалізацію пошуку на карті лабіринту в графічному інтерфейсі Tkinter
- Одночасний розвиток двох хвиль:
  - хвиля A розповсюджується від старту
  - хвиля B розповсюджується від фінішу
- Пошук точки зустрічі двох фронтів і відновлення найкоротшого маршруту
- Підтримку різних правил переміщення:
  - 4 напрямки: вгору, вниз, вліво, вправо
  - 4 діагоналі
  - 8 напрямків (поєднання основних і діагональних ходів)
- Опцію "Не зрізати кути", яка забороняє переходи по діагоналі через стіни
- Генерацію випадкового лабіринту, завантаження та збереження стану
- Відображення статистики, журналу пошуку і знайденого шляху

## Принцип роботи алгоритму
Двонаправлений хвильовий пошук працює так:

1. Від стартової клітинки будується перша хвиля.
2. Від цільової клітинки одночасно будується друга хвиля.
3. Обидва фронти розширюються рівно по одному шару за ітерацію.
4. Коли хвиля A і хвиля B торкаються однієї і тієї ж клітинки або сусідніх клітин, пошук завершується.
5. Далі від точки зустрічі відновлюється шлях назад до старту та вперед до мети.

Для кожної клітини зберігається відстань від відповідного кінця, а в момент зустрічі обчислюється найкоротший шлях як сума двох відстаней.

Це дає перевагу над однонаправленим варіантом: замість того, щоб розширюватися лише від початку, пошук зближується з обох боків, тому в середньому число перевірених клітин виявляється меншим.

## Запуск
1. Перейдіть у корінь проєкту.
2. Встановіть залежності:
   ```bash
   pip install -r lab4/requirements.txt
   ```
3. Запустіть застосунок:
   ```bash
   python lab4/main.py
   ```

## Структура проєкту
- `lab4/main.py` — точка входу програми
- `lab4/app.py` — графічний інтерфейс і логіка взаємодії з користувачем
- `lab4/maze.py` — модель лабіринту, операції переміщення та реалізація однопрохідного і двонаправленого хвильового пошуку
- `lab4/results/` — результати та експериментальні дані
- `lab4/maze/` — файли з прикладами лабіринтів і конфігураціями

## Алгоритмічна особливість
У проєкті реалізовано два варіанти пошуку:
- `wave_search` — класичний однонаправлений хвильовий пошук
- `bidirectional_search` — двонаправлений варіант, який працює з двома фронтами пошуку

## Примітка
Проєкт призначений для навчальних цілей і демонстрації того, як працює двонаправлений пошук у лабіринті, а також для порівняння його ефективності з однонаправленим алгоритмом Лі.
