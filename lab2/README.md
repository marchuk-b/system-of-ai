# DFS

## Запуск
1. Перейдіть у папку проекту.
2. Встановіть залежності:
   ```bash
   pip install -r lab2/requirements.txt
   ```
3. Запустіть застосунок:
   ```bash
   python lab2/main.py
   ```

## Структура проекту
- `lab2/main.py` — точка входу
- `lab2/app.py` — інтерфейс та логіка пошуку
- `lab2/graph.py` — дані графа та стилізація
- `lab2/graphs/` — приклади графів
- `lab2/results/` — результати пошуку

## Примітка
Проект призначений для навчальних цілей і демонстрації роботи алгоритму DFS на візуальному графі та порівнянні його роботи з алгоритмом BFS.
