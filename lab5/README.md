# Алгоритм Дейкстри

## Запуск
1. Перейдіть у корінь проєкту.
2. Встановіть залежності:
   ```bash
   pip install -r lab5/requirements.txt
   ```
3. Запустіть застосунок:
   ```bash
   python lab5/main.py
   ```

## Структура проекту
- `lab5/main.py` — точка входу
- `lab5/app.py` — інтерфейс і логіка пошуку
- `lab5/graph.py` — дані графа та стилізація
- `lab5/graphs/` — приклади графів
- `lab5/img/bg.jpg` — фонове зображення карти України
- `lab5/results/` — результати пошуку

## Примітка
Проєкт призначений для навчальних цілей і демонстрації роботи алгоритму Дейкстри на графі автомобільних шляхів України.
