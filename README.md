# BFS

## Запуск
1. Перейдіть у папку проекту.
2. Встановіть залежності:
   ```bash
   pip install -r lab1/requirements.txt
   ```
3. Запустіть застосунок:
   ```bash
   python lab1/main.py
   ```

## Структура проекту
- `lab1/main.py` — точка входу
- `lab1/app.py` — інтерфейс та логіка пошуку
- `lab1/graph.py` — дані графа та стилізація
- `lab1/graphs/` — приклади графів
- `lab1/results/` — результати пошуку

## Примітка
Проект призначений для навчальних цілей і демонстрації роботи алгоритму BFS на візуальному графі.
