# Однонаправлений хвильовий пошук у лабіринті

Навчальний проект для візуалізації роботи алгоритму пошуку шляху в лабіринті. Додаток демонструє, як працює хвильовий (пошук у ширину) алгоритм на сітці з перешкодами, дозволяє вибирати тип переміщення, змінювати лабіринт і спостерігати процес знаходження маршруту.

## Основні можливості
- Візуалізація лабіринту у графічному інтерфейсі на Tkinter
- Пошук шляху від старту до мети за допомогою хвильового алгоритму
- Підтримка переміщення:
  - 4 напрямки: вгору, вниз, вліво, вправо
  - 4 діагоналі
  - 8 напрямків (поєднання чотирьох основних і чотирьох діагональних)
- Опція "Не зрізати кути" для заборони переходів через стіни по діагоналі
- Генерація випадкового лабіринту або завантаження/збереження стану
- Відображення журналу пошуку, статистики і знайденого маршруту

## Запуск
1. Перейдіть у корінь проєкту.
2. (Опційно) встановіть залежності:
   ```bash
   pip install -r lab3/requirements.txt
   ```
3. Запустіть застосунок:
   ```bash
   python lab3/main.py
   ```

## Структура проєкту
- `lab3/main.py` — точка входу програми
- `lab3/app.py` — графічний інтерфейс та логіка взаємодії з користувачем
- `lab3/maze.py` — опис лабіринту, операції переміщення та реалізація хвильового пошуку
- `lab3/results/` — результати та експериментальні дані
- `lab3/maze/` — файли з примірниками лабіринтів/настройками

## Алгоритм
Проєкт реалізує однонаправлений хвильовий пошук (алгоритм Лі), який послідовно розширює фронт пошуку від стартової клітинки до цілі. Для кожної клітинки зберігається відстань до початку, а потім відбувається відновлення шляху від мети до старту.

## Примітка
Проєкт призначений для навчальних цілей і демонстрації роботи алгоритму пошуку шляху в лабіринті з візуалізацією процесу.
